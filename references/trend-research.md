# 近30天同类内容趋势研究

本流程用于“只给主题/需求”或用户明确要求参考当前趋势的内容生产任务。目标是形成**公开可见样本中的点赞 Top20**，再提炼标题、正文与视觉呈现中可借鉴的内容结构；它不是小红书官方全站榜单、平台推荐算法结论或流量保证。

## 1. 研究边界

### 1.0 站内检索硬性门禁

- 触发条件：任务出现“趋势研究、同类内容、爆文、Top20、当前热门”等调研要求，或用户只给主题/需求并要求生成内容。
- 第一动作：必须使用内置浏览器打开小红书站内搜索页、公开笔记页或用户提供的小红书链接，并先记录 `browser_route: in_app`、`site_search_status: started`。这只表示开始尝试，不表示访问成功；不得直接选择外置浏览器或桥接。
- 门禁未通过前，禁止生成文案、输出趋势结论、调用通用互联网搜索，或把搜索引擎结果当作小红书站内样本。内置浏览器明确技术失败后，才可按外置 Edge/Chrome、Playwright + Edge 桥接的顺序逐级尝试；每次跳转必须记录失败原因。
- **访问成功证据**：进入样本采集前，必须向用户展示 `browser_evidence_status: confirmed`，并同时给出实际 `page_url`、`page_title`、`page_identity: xiaohongshu`、`search_query`、`search_state`（`results` / `no_results` / `blocked`）以及页面实际可见的前 3 条结果摘要（标题、可见点赞、发布时间、链接；不足 3 条如实列出）。仅打开首页、空白页、登录页或搜索框，不得标记为 `confirmed`，也不得声称已搜索到样本。能截图时一并展示截图或截图路径；不能截图时展示可读页面文本或 DOM 证据。
- **打开后必须读取并恢复**：打开目标页后立即读取 URL、标题、可见文本/可访问性树/DOM、页面身份与状态，并获取截图。窗口出现不算成功。读取为空、超时、报错或身份不明时，固定执行并逐次记录 `read_attempt`、`read_status`、`read_error`、`recovery_action`：第 1 次等待 3-5 秒重读；第 2 次刷新当前标签页重读；第 3 次在内置浏览器新标签页重开目标 URL 重读；第 4 次读取浏览器诊断信息。每次都要重读文本和截图；截图可见但文本/DOM 失败时用截图作为证据并展示路径。登录、扫码、验证码/滑块、人工确认标为 `blocked`，请求用户处理，不得当作技术失败或切换浏览器。四次仍失败才记 `xhs_site_access: read_blocked` 并说明全部错误，之后才可按顺序逐级切换，不得直接桥接。
- 只有站内访问失败并且用户明确回复“确认使用公开网页调研”后，才允许走降级路径；完整内容且用户没有要求趋势研究时，才可以不做趋势研究。


- 以当前日期和 `Asia/Shanghai` 时区计算时间窗：默认为最近30个自然日，记录明确的起止日期。
- 先定义“同类”：主题、目标读者、使用场景和内容目的至少匹配两项；泛相关内容只作为旁证，不混入 Top20。
- 默认样本来源是已实际打开的小红书站内搜索结果、公开笔记页或用户提供的站内链接；必须先完成站内访问门禁，搜索引擎或其他公开网页只能在用户明确授权的降级路径中使用。
- 通过 2-5 组检索词覆盖主题词、痛点词、场景词和人群词，记录每个样本命中的检索词。
- 去重优先按笔记 URL、笔记 ID，其次按“标题 + 作者 + 发布时间”；同一笔记多次出现只保留一次。

检索工具按以下顺序选择，并把“实际打开小红书站内页面”作为不可跳过的门禁：

1. **内置浏览器（必须先尝试）**：先使用当前会话的内置浏览器打开小红书公开搜索页、公开笔记页或用户提供的站内链接，并记录 `browser_route: in_app`、实际 URL、搜索词、筛选条件和页面可见字段。不得因为外置浏览器或桥接已连接、已有登录态或更方便而跳过本步。
2. **处理登录或页面访问失败**：页面要求登录、扫码、验证码或人工确认时，停留在当前已选浏览器并请求用户处理；默认每 10-30 秒检查一次、最多等待 120 秒，期间不得自动切换浏览器。登录等待超时仍不等于内置浏览器技术失败；先输出 `xhs_site_access: unavailable` 和原因，等待用户决定是否切换或授权降级。
3. **站内访问不能完成时停止并询问**：浏览器/桥接不可用、站内页面无法打开，或登录等待超时后，输出 `xhs_site_access: unavailable` 和具体原因，并请用户选择“提供小红书链接/截图”“确认跳过趋势研究”或明确回复“确认使用公开网页调研”。未获得该明确回复前，不得直接使用通用互联网、搜索引擎或其他公开网页进行调研。
4. **仅在明确授权后降级**：用户明确确认“使用公开网页调研”后，才可使用能够打开并核验的公开网页；搜索引擎摘要不得单独作为点赞数、发布时间或正文证据。结果必须标记 `research_route: public_web_fallback_authorized`、站内访问失败原因和研究局限，且不得称为“小红书站内调研”或“小红书站内 Top20”。
5. **无可用路径**：没有可用浏览器/桥接，且用户未授权公开网页调研时，输出 `trend_research: unavailable`，请求用户提供样本链接/截图或确认跳过研究；不得用模型记忆补齐 Top20，也不得把凭经验生成的内容包装成当前趋势结论。

## 2. 采集与排名

对每条候选记录以下字段：

| 字段 | 要求 |
|---|---|
| rank | 按可见点赞数降序重排，缺失点赞数的样本不进入严格 Top20 |
| title / url | 原样记录标题和可访问链接，不复制正文 |
| author | 仅记录公开显示的账号名；不推断身份或商业关系 |
| published_at | 记录页面显示的发布时间，无法确认则标 `待核验` |
| likes / collects / comments | 原样记录页面可见值，并注明“页面显示”；不能把收藏或评论当点赞 |
| query | 命中的检索词 |
| cover_promise | 用自己的话概括封面承诺 |
| visual_scope | 实际看过的封面、轮播图页码、截图或视频关键帧；未加载/未看清时如实记录 |
| visual_analysis | 用自己的话概括画面主体、图内可读信息、证据类型、信息顺序和视觉节奏；不逐字转录图中文字 |
| opening_hook | 用自己的话概括前几秒/首段入口 |
| structure | 综合文字与视觉信息记录顺序、页间节奏和主要机制，不抄原文或图中文字 |
| interaction | 记录收藏、评论或私信的理由 |
| evidence / disclosure | 记录是否有实拍、数据来源、案例边界、商业披露等 |
| risk_flags | 记录绝对化、收益承诺、导流、版权、营销或事实待核验候选 |

排名规则：先按时间窗过滤，再按可见点赞数从高到低排序，最后取前20条。平台显示“热门”或“综合”而不是点赞排序时，必须记录实际排序方式，不能把页面顺序直接写成点赞 Top20。点赞显示为“1.2万”等缩写时可转换为数值用于排序，但同时保留原始显示值。

如果严格样本少于20条，输出实际数量并说明原因；不得用时间窗外、不同主题或无法核验的数据凑满20条。站内页面不可访问时，先按站内访问门禁向用户说明并等待选择；只有用户明确授权后才能使用公开网页降级，仍无法验证时标为“趋势研究不可核验”，不能虚构样本。

### 2.1 视觉内容读取

- Top20 的排名仍只按时间窗内**页面可见点赞数**决定；视觉识别用于补全样本理解，不作为排序替代项。
- 对已实际打开的公开笔记，优先查看封面、可加载的轮播图、正文截图/图表、实拍证据，以及视频的首帧和能实际播放/定位到的少量关键帧；调研不限于文字笔记。
- 有图像理解或 OCR 能力时，只提取能清楚辨认且与主题相关的信息；没有该能力、图片未加载、文字过小或画面模糊时，记录 `visual_status: unreadable`，不得补猜。
- 输出使用“画面展示了……”“图内可读信息概括为……”等释义，不逐字转录大段图中文字，不下载、保存、复用或再发布样本图片、视频帧、截图、模板或专属案例。
- 不把滤镜、构图、出镜人、截图或图表单独归因为点赞原因；最多写“在本样本中同时出现”。涉及数字、资质、商品效果、政策或案例时，仍要按页面可见来源和事实边界复核。

## 3. 逐条分析与聚合

逐条分析只提炼以下结构：点击入口、首段承诺、单一核心机制、文字与视觉证据/真人感、页面或段落节奏、互动理由、风险候选。不要输出长段摘抄，不要复刻原文标题、封面文案、图中文字或图片。

完成逐条记录后，按以下维度聚合：

1. **重复出现**：多个独立样本共同出现的痛点、场景、文字或视觉表达形式和互动动作。
2. **高点赞但不可归因**：只能写“在本样本中同时出现”，不能断言该因素导致点赞高。
3. **时间节点**：区分短期时事/季节性话题与长期问题；时效性事实必须另行核验。
4. **内容缺口**：样本普遍没有回答、但目标读者仍可能需要的信息。
5. **可迁移结构**：只保留可原创化的方法、顺序和问题，不复制具体表达。

## 4. 概要输出格式

在生成文案前先输出并内部确认以下概要：

```text
研究窗口：YYYY-MM-DD 至 YYYY-MM-DD（Asia/Shanghai）
调研路径：xhs_site / public_web_fallback_authorized / unavailable
站内访问证据：
browser_evidence_status: confirmed / unavailable
browser_route: in_app / external / bridge
page_url: 实际 URL
page_title: 页面标题
page_identity: xiaohongshu / unknown
search_query: 实际搜索词
search_state: results / no_results / blocked
visible_results: 前 3 条可见结果摘要（标题、点赞、发布时间、链接）
证据展示：截图路径或可读页面文本 / DOM
站内访问：实际打开 URL / 登录等待 / 失败原因
视觉读取：已查看的封面/轮播图/视频关键帧范围；未读原因
主题与同类定义：
检索词：
样本：严格可核验 __ 条；公开样本 Top20 / 不足20条 / 无法核验
研究局限：

目标读者：
当前核心问题：
本篇增长任务：拉新 / 建立信任 / 强化标签
当前时间节点角度：观察 / 推测 / 待核验
唯一核心机制：
标题触发器：
内容结构：
视觉结构与证据类型：
封面承诺：
收藏或评论理由：
必须补充的事实、数据、案例、来源或授权：
```

概要经事实边界检查后，再进入文案生产。若用户要求直接生成，可在同一轮中先给概要再给初稿，不必额外等待确认；涉及政策、收益、医疗、金融、身份或商业合作的高风险主题，先补证据或暂停生成相关断言。

## 5. 研究结果的引用边界

- 输出样本表和分析时保留链接、公开指标、发布时间和检索日期，方便复核。
- 公开点赞数只能作为样本排序字段，不能写成点击率、转化率、停留时长或平台偏好。
- 不复制样本正文、封面图片、图片文字、账号人设、客户案例或未授权素材。
- 若最终文案受到样本启发，在内部记录 `trend_research: completed` 和样本范围；不要向用户声称“按爆文改写”或“保证获得流量”。

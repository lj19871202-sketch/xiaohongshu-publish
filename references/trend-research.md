# 近30天同类内容趋势研究

本流程用于“只给主题/需求”或用户明确要求参考当前趋势的内容生产任务。目标是形成**公开可见样本中的点赞 Top20**，再提炼可借鉴的内容结构；它不是小红书官方全站榜单、平台推荐算法结论或流量保证。

## 1. 研究边界

- 以当前日期和 `Asia/Shanghai` 时区计算时间窗：默认为最近30个自然日，记录明确的起止日期。
- 先定义“同类”：主题、目标读者、使用场景和内容目的至少匹配两项；泛相关内容只作为旁证，不混入 Top20。
- 使用公开可访问的小红书搜索结果、笔记页或用户提供的链接；优先使用站内搜索和可见排序，搜索引擎结果只能作为补充。
- 通过 2-5 组检索词覆盖主题词、痛点词、场景词和人群词，记录每个样本命中的检索词。
- 去重优先按笔记 URL、笔记 ID，其次按“标题 + 作者 + 发布时间”；同一笔记多次出现只保留一次。

检索工具按以下顺序选择：

1. 有浏览器控制能力时，打开小红书公开搜索/笔记页面，记录实际搜索词、筛选条件和页面可见字段。若页面要求登录，先在当前浏览器停留并请求用户登录；默认每 10-30 秒检查一次、最多等待 120 秒，期间不自动切换浏览器。
2. 没有站内浏览器控制但有公开网页检索能力时，只使用能够打开并核验的页面；搜索引擎摘要不得单独作为点赞数、发布时间或正文证据。
3. 当前浏览器等待超时且用户未指定浏览器时，才切换到可用的 Edge 会话，并在切换前告知用户；若用户指定了浏览器，保持原浏览器并继续等待或请求用户处理登录。
4. 没有可用浏览器或公开网页检索能力时，明确输出 `trend_research: unavailable`，请求用户提供样本链接/截图或确认跳过研究；不得用模型记忆补齐 Top20，也不得把凭经验生成的内容包装成当前趋势结论。

## 2. 采集与排名

对每条候选记录以下字段：

| 字段 | 要求 |
|---|---|
| rank | 按可见点赞数降序重排，缺失点赞数的样本不进入严格 Top20 |
| title / url | 原样记录标题和可访问链接，不复制正文 |
| author | 仅记录公开显示的账号名；不推断身份或商业关系 |
| published_at | 记录页面显示的发布时间，无法确认则标 `待核验` |
| likes / collects / comments | 原样记录页面可见值，并注明“页面显示”；不能把收藏或评论当点赞 |
| query | 命中的检索词 |
| cover_promise | 用自己的话概括封面承诺 |
| opening_hook | 用自己的话概括前几秒/首段入口 |
| structure | 记录信息顺序、页间节奏和主要机制，不抄原文 |
| interaction | 记录收藏、评论或私信的理由 |
| evidence / disclosure | 记录是否有实拍、数据来源、案例边界、商业披露等 |
| risk_flags | 记录绝对化、收益承诺、导流、版权、营销或事实待核验候选 |

排名规则：先按时间窗过滤，再按可见点赞数从高到低排序，最后取前20条。平台显示“热门”或“综合”而不是点赞排序时，必须记录实际排序方式，不能把页面顺序直接写成点赞 Top20。点赞显示为“1.2万”等缩写时可转换为数值用于排序，但同时保留原始显示值。

如果严格样本少于20条，输出实际数量并说明原因；不得用时间窗外、不同主题或无法核验的数据凑满20条。若站内页面不可访问，先尝试可用的公开搜索/用户链接；仍无法验证时，降级为“趋势研究不可核验”，不能虚构样本。

## 3. 逐条分析与聚合

逐条分析只提炼以下结构：点击入口、首段承诺、单一核心机制、证据/真人感、页面或段落节奏、互动理由、风险候选。不要输出长段摘抄，不要复刻原文标题、封面文案或图片。

完成逐条记录后，按以下维度聚合：

1. **重复出现**：多个独立样本共同出现的痛点、场景、表达形式和互动动作。
2. **高点赞但不可归因**：只能写“在本样本中同时出现”，不能断言该因素导致点赞高。
3. **时间节点**：区分短期时事/季节性话题与长期问题；时效性事实必须另行核验。
4. **内容缺口**：样本普遍没有回答、但目标读者仍可能需要的信息。
5. **可迁移结构**：只保留可原创化的方法、顺序和问题，不复制具体表达。

## 4. 概要输出格式

在生成文案前先输出并内部确认以下概要：

```text
研究窗口：YYYY-MM-DD 至 YYYY-MM-DD（Asia/Shanghai）
主题与同类定义：
检索词：
样本：严格可核验 __ 条；公开样本 Top20 / 不足20条 / 无法核验
研究局限：

目标读者：
当前核心问题：
本篇增长任务：拉新 / 建立信任 / 强化标签
当前时间节点角度：观察 / 推测 / 待核验
唯一核心机制：
标题触发器：
内容结构：
封面承诺：
收藏或评论理由：
必须补充的事实、数据、案例、来源或授权：
```

概要经事实边界检查后，再进入文案生产。若用户要求直接生成，可在同一轮中先给概要再给初稿，不必额外等待确认；涉及政策、收益、医疗、金融、身份或商业合作的高风险主题，先补证据或暂停生成相关断言。

## 5. 研究结果的引用边界

- 输出样本表和分析时保留链接、公开指标、发布时间和检索日期，方便复核。
- 公开点赞数只能作为样本排序字段，不能写成点击率、转化率、停留时长或平台偏好。
- 不复制样本正文、封面图片、图片文字、账号人设、客户案例或未授权素材。
- 若最终文案受到样本启发，在内部记录 `trend_research: completed` 和样本范围；不要向用户声称“按爆文改写”或“保证获得流量”。

# 内容生产：调研、文案、素材与配图

> 本文是**参考流程**，其中「德阳跨境电商产业园」的 10 篇系列结构仅为示例，帮助理解执行方式；实际内容以用户输入为准，用户给出主题、要点或文案后按同样流程产出。

## 0. 通用生产原则

- 当输入只有主题/需求，或用户要求参考当前趋势时，先读取并执行 [trend-research.md](trend-research.md)，完成近30天同类样本研究和概要提炼，再进入文案撰写；用户明确跳过研究时记录 `trend_research: skipped_by_user`。
- 先确认目标读者、真实问题和本篇任务：拉新、建立信任或强化标签；没有明确目标时先用一个最小问题补齐，不要直接批量生成空泛标题。
- 每篇只保留一个核心机制。先回答“解决谁的问题、为什么现在点进来、看完带走什么”，再决定标题、正文和图片。
- 标题必须能追溯到触发器（痛点、数字、对比、稀缺、共鸣、资源、反常识等），并能落成一个明确的封面钩子；`≤20` 字是发布页面硬校验，其他数量和频率都是可调整假设。
- 优先使用用户提供的经历、动作、数据、案例和原始资料。没有来源时用 `[待补材料]` 或 `待核验`，不得把推测、收益、政策或案例写成事实。
- 如果要做对标，优先记录近期、粉丝量与内容数据相对匹配的样本，分别拆“点击入口、文字与视觉停留结构、互动理由”；可分析实际打开的封面、轮播图和视频关键帧，只提取结构，不复制原文、图中文字、图片、视频帧或专属模板；没有可访问样本时如实说明，不虚构搜索结果。
- 发布前进行两层预审：先扫候选表达，再按意图、证据、授权、商业关系和标题—封面—正文一致性复核；修复后重新检查全文和图片文字。

## 0.1 趋势研究后的概要字段

生成初稿前先形成一页内容概要，至少包含：

- 研究窗口、检索词、样本数量和样本局限；
- 当前目标读者与核心问题；
- 样本中重复出现的点击入口、开头承诺、文字与视觉内容结构、证据类型和互动理由；
- 当前时间节点仍然成立的内容角度，以及仅适用于样本当时的短期话题；
- 本篇唯一核心机制、标题触发器、封面承诺、收藏/评论理由；
- 必须补充的真实经历、数据、来源、授权和商业关系。

概要中把结论标为 `观察`、`推测` 或 `待核验`，不把点赞高写成内容一定有效，也不把样本中的数字或案例直接当作本篇素材。

## 1. 竞品调研（Top5 整理）

- 搜索关键词组合：`城市/主题 + 找工位`、`共享工位`、`共享办公`、`自习室` 等；补充竞对品牌名查同类笔记。
- 结果按「笔记 / 发布时间 / 关键信息」整理成表格，附 xiaohongshu.com 链接；如实说明公开搜索索引的时效限制（网页端看不到“最新发布”排序，商家帖会重复置顶）。
- 用户要求“最近一个月”时，先按时间筛选；无新帖时如实报告，给出最新可查 Top5 并建议在小红书 App 内按“最新发布”筛选。
- 每个样本额外记录：账号粉丝量、发布时间、点赞/收藏/评论、封面标题承诺、开头、正文结构、结尾动作和标签；不要只按点赞排序。
- 用“点击率 / 停留时长 / 互动率”做诊断框架，但没有后台数据时只写“推测强项”，不得把公开互动量当成真实点击率或停留时长。

## 2. 系列文案撰写（按用户输入调整）

- 参考结构：招商 + 科普 + 服务 + 圈子引流 多篇矩阵；每篇含：标题备选（2 个）、小红书风格正文（口语化 + emoji + 短段落 + 痛点切入 + 行动引导）、话题标签（5-7 个）、配图建议。
- 内容来源：用户提供的政策/卖点/服务信息 + 网上补充的公开数据；引用数据标注“发布前由运营方核对最新口径”，政策类表述统一加“以官方最新解释为准”。
- 输出：Markdown 主文档（可选 Word docx）。本机无 LibreOffice 时，用结构审计（表格几何、标题层级、样式 token）替代渲染 QA，并向用户如实说明。
- 每篇增加：目标读者、用户底层需求（情感共鸣 / 见证成长 / 获得新知 / 学习提升 / 身份表达）、标题触发器、收藏/评论理由、封面钩子和视觉交接字段。
- 初稿先诊断再改写：检查前 5 秒、单一核心机制、真实背景、3 点以内信息、结尾互动和图文页间节奏；“去 AI 味”不是简单换口语，而是补充具体的人和证据。

## 3. 单篇素材拆分（用户内容入库）

- 用户提供一篇或多篇内容时，按 `小红书发布素材\<图片|视频|文字>\NN_主题\` 组织：文字素材命名为 `NN_主题.txt` 放入 `文字\NN_主题\`，同主题的配图、实拍图放入 `图片\NN_主题\`，视频放入 `视频\NN_主题\`。
- 格式（发布包脚本依赖这些节标题）：

  【标题】
  【备选标题】
  【正文】
  【话题标签】
  【配图建议】
  【发布参数】（含 `封面图：路径`、备选封面、轮播图、建议发布时间、注意事项）

## 4. 配图库建设（按用户素材）

- 目录：`小红书发布素材\图片\NN_主题\`（原独立配图库并入该目录）；README 登记每篇配图清单与实拍图状态。
- 模板图：PIL 大字报风格——封面 1242×1656（3:4，信息流优先展示），每篇一个主题色、突出核心利益点；要点卡 1080×1080（1:1），卖点编号清单。
- 实拍封面：横版实拍图裁成 3:4 竖版，顶部大字标题 + 完整画面 + 底部品牌条。
- 规范：首图 3 秒讲清利益点，字号 >80px；每篇 1-9 张图，建议 1 封面 + 3-6 内容图；实拍图优先于模板图。
